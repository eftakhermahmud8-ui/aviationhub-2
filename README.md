## About

**Aviation Hub** is a multipage web platform built for aviation enthusiasts, spotters, and professionals. It brings together detailed information and photos of **planes, jets, and airports**, along with **live aviation news** — all in a single, easy-to-navigate hub.

Version 2 rebuilds the platform from the ground up with a cleaner UI, user-contributed content, and a much richer database.


---

## What's New in v2

- Redesigned multipage layout — smoother navigation across Aircraft, Airports, News, and Gallery
- User uploads — contribute info and photos for any aircraft or airport
- Live aviation news feed — stay updated with the latest in the industry
- Enhanced photo galleries — high-quality spotting photos with metadata
- Search and filters — find planes by manufacturer, model, airline, or registration
- User profiles — track your contributions and favorite aircraft

## Features

- **Aircraft database** — planes and jets with specs, operators, and photos
- **Airport database** — codes (IATA/ICAO), location, runways, terminals, and images
- **Live news feed** — aggregated aviation news from trusted sources
- **User uploads** — add photos or info for aircraft and airports
- **Smart search** — by name, model, airline, registration, or airport code
- **Favorites** — save aircraft and airports for quick access
- **Responsive design** — works on desktop, tablet, and mobile

## Getting Started

1. Fork or clone the repository.
2. Open `index.html` in your browser, or visit the live site.
3. Explore aircraft, airports, news, and gallery pages.
4. Use the Upload page to contribute info or photos.

---

## Hosting

This project is hosted on **GitHub Pages**. Any changes pushed to the `main` branch are automatically deployed.

To deploy your own copy:
1. Push the project to a GitHub repository.
2. Go to **Settings → Pages**.
3. Set the source to the `main` branch and save.
